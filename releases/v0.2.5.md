# BLINK-AI v0.2.5

The package includes BLINK-AI and native executables for macOS ARM64 and Windows x86-64.

- Automatically prepare the project R library and install missing `jsonlite` when running an analysis.
- Generate Manhattan and QQ plots with the bundled GAPIT functions and record their names and styles with the results.
- Create local feedback reports that preserve user requirements and experience and attach run evidence.
- Capture failed analyses, dependency setup failures, and conversion errors.
- Track handling status, code changes, validation evidence, applicable versions, and local regression cases.
- Start GWAS at 2,000 SNPs per block and resume with smaller blocks after a block workspace allocation failure.

Install Python 3.9 or later and R. The setup command prepares the R dependencies used by the skill. Use `--no-install` or `BLINK_AI_INSTALL_R_PACKAGES=false` to check installed packages without downloading dependencies.

The macOS workflow has been tested end to end. The Windows executables have been checked for architecture and integrity. Run the bundled demo on your platform to check the installation.
