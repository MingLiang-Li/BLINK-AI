# BLINK-AI v0.2.4

The package includes the BLINK-AI skill and native executables for macOS ARM64 and Windows x86-64.

- Convert between PLINK binary, VCF, VCF.gz, Numeric, HapMap, and BLINK formats.
- Run BLINK and GLM GWAS with sample alignment, trait selection, covariates, and quality control.
- Start GWAS with a block limit of 2,000 SNPs and reduce the block in the same process when workspace allocation fails.
- Generate per-trait Manhattan and QQ plots, multiple-testing corrections, and English analysis reports.
- Run phenotype simulation and evaluation using the bundled GAPIT functions.

Python 3.9 or later, R, and `jsonlite` are required for the complete analysis workflow. The macOS workflow has been tested end to end. The Windows executables have been checked for architecture and integrity. Use the bundled demo to check the installation on your platform.
