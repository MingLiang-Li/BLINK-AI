# BLINK-AI v0.2.6

- Accelerate full hard-call validation for VCF, VCF.gz, PLINK binary, Numeric, HapMap, and BLINK input using lookup tables and bulk byte operations.
- Record elapsed time by conversion stage and native command in `conversion.json`.
- Preserve genotype identity, allele orientation, sample and marker metadata, missingness policies, and final output checks.

The package includes native executables for macOS ARM64 and Windows x86-64. Individual conversions execute sequential stages. See [performance and resource use](../blink-ai/references/performance.md) for storage choices and concurrent independent conversion tasks.
