# BLINK-AI 0.2.7

- Make the bundled rice dataset the default GWAS demo: six VCF.gz chunks, 413 sample IDs, one measured trait, and four supplied PCs.
- Standardize example filenames and recover unique sample IDs using matched reference genotypes. Preserve the supplied genotype and phenotype values.
- Document data preparation, missingness, model settings, and the macOS reference result.
- Add a practical usage guide covering agent prompts, local installation, JSON configuration, multi-file GWAS, format conversion, simulation, outputs, and feedback.

The native executables are unchanged. Windows x86-64 binaries are included with verified architecture and integrity; execution of the new example on Windows remains pending.
